## 5. Architecture rules (Clean Architecture, 3 layers)

```
src/
├── domain/           # Pure Python. NO imports from application or infrastructure.
├── application/      # Imports from domain ONLY. Receives infra via DI.
└── infrastructure/   # Implements domain interfaces. Imports anything.
```

**Hard rules:**
- `domain/` files: no `fastapi`, no `sqlalchemy`, no `google.generativeai`, no `pydantic` (use `dataclass` + plain Python).
- `application/` files: may import from `domain`, may import `pydantic` for DTOs, must NOT import from `infrastructure`. Services receive repos and AI service as constructor args.
- `infrastructure/` files: free to import anything.
- Repository pattern: domain defines `IProductRepository`/`IChatRepository` (ABC), infrastructure implements `SQLProductRepository`/`SQLChatRepository`.
- Dependency Injection: services never instantiate their dependencies; the FastAPI endpoint wires them up using `Depends(get_db)`.

If a file would break a layer rule, stop and re-read this section.

## 10. Code conventions

- **Type hints everywhere** — every function signature.
- **Docstrings:** Google style, in **Spanish** (the workshop is Spanish-speaking and grades doc explicitly). Pattern:
  ```python
  def reduce_stock(self, quantity: int) -> None:
      """
      Reduce el stock del producto en la cantidad indicada.

      Args:
          quantity: Cantidad a descontar. Debe ser positiva.

      Raises:
          ValueError: Si quantity es negativa o supera el stock disponible.
      """
  ```
- **No `print` statements** in production code. (Use them only inside `if __name__ == "__main__":` blocks for `init_data.py` if needed.)
- **No emojis in code or commits.**
- **No comments restating the code.** Comments explain *why*, not *what*. The exception is the `# Fix 2da vuelta: ...` markers from §3.
- **String formatting:** f-strings.
- **Imports:** stdlib → third-party → local, separated by blank lines.

### `src/application/dtos.py`
Use `@field_validator` (Pydantic v2). Add `# Fix 2da vuelta: @validator es deprecated en pydantic v2, usamos field_validator` comment on first usage.

```python
from pydantic import BaseModel, field_validator

class ProductDTO(BaseModel):
    ...
    @field_validator("price")
    @classmethod
    def price_must_be_positive(cls, v: float) -> float:
        if v <= 0:
            raise ValueError("price must be greater than 0")
        return v
```

### `src/infrastructure/llm_providers/gemini_service.py`
